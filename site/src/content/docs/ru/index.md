ducktainer управляет Docker из одного бинарного файла. Вы получаете веб-интерфейс с контекстными меню по правой кнопке везде, сохранёнными представлениями, канбан-доской и палитрой ⌘K. Также есть стеки compose с визуальным редактором, каталог приложений, логи в реальном времени и веб-терминалы.

Вход выполняется под **системными учётными записями** (PAM). Доступ к сети ограничен адресами, которые вы разрешили.

## Как это работает

- **Агенты не нужны.** К удалённым хостам подключаются по **SSH** (`docker system dial-stdio`, как `DOCKER_HOST=ssh://`) или через `ducktainer expose`. От них нужен только Docker. Для хостов за NAT есть необязательный агент исходящего подключения.
- **Минимум привилегий.** Служба работает от непривилегированного пользователя. `ducktainer setup` подстраивается под то, как установлен Docker: группа сокета, rootless или только root. Проверки паролей выполняются от root, во вспомогательном процессе, который запускается по требованию.
- **Контроль доступа.** Список разрешённых IP/CIDR/имён хостов отбрасывает подключения до TLS. Роли берутся из групп POSIX. TLS настраивается автоматически, с закреплением сертификата, а каждое действие попадает в журнал аудита.
- **Языки.** Английский, испанский и русский. Интерфейс следует языку браузера и переключается через меню пользователя; CLI следует переменной `LANG`.

## С чего начать

1. [Установите](install/) пакет и проверьте, как он подключается к Docker.
2. [Предоставьте пользователям доступ](access/) и откройте его для своей сети.
3. [Добавьте хосты](hosts/) по SSH, через агент или `ducktainer expose`.

Страницы [командная строка](cli/) и [файлы](files/) служат справочником по всему остальному.
